# GSC-20261023：語言 canonical 與舊 slug 轉址

負責：Claude Opus 5.5（程式、測試、部署）。Search Console 提交與 Google 側驗證由 Codex 負責；本文件不代表任何 URL 已被索引。

## 起始狀態（使用者提供，10/23）

GSC 已索引 31、未索引 295（265 已檢索未索引、24 重新導向、4 個 404、2 個 Google 選擇不同 canonical）。10/23 已重送 `/sitemap.xml`，Google 讀到 450 URL。

## 根因

1. **canonical 與 Sitemap 不一致**：`render_shell.render_document` 一律輸出 `?lang=<語言>` canonical，無參數 URL 由 Accept-Language 決定語言（Googlebot 得到 en）。Sitemap 的 450 個無參數 URL 中，373 個殼頁 canonical 指向 `?lang=en`，不是 Sitemap 列出的 URL。`web/assets/app.js` `updateMetadata()` 在 JS 渲染後也同樣改寫為 `?lang=`。
2. **舊 slug 404**：`data/sources/source-url-aliases.csv`（395 列 301，2026-07-05 驗證）只輸出成 Cloudflare bulk redirects；改由本機 `serve.py` 服務後無任何程式讀取，全部變 404。`validate_legacy_redirects.py --live` 自那時起即失敗（修復前實測 4/4 錯）。
3. **舊 feed 404**：`/feeds/sources.xml` 的 `<guid>https://harmonica.observe.tw/feeds/sources/<hash></guid>` 未標 `isPermaLink="false"`，RSS 2.0 預設視為 permalink；這些 URL 從未是頁面。三個 hash（`84728e2c079cfc9a`、`4d9fa96c04d0d7e3`、`8c3b4a4ba4c7bdbe`）仍在目前 feed 中，是 GUID 而非可對應的實體，故不轉址、保留 404。

## 修復

- 語言策略：無參數 URL 固定為英文、自我 canonical、`hreflang="en"` 與 `x-default`；`?lang=en` canonical 指向無參數 URL（不轉址，以免破壞前端 `?lang` 優先順序）；`?lang=zh-Hant|ja|ko` 自我 canonical。每頁 5 個 hreflang。伺服器端內部連結英文也使用無參數 URL。前端語言切換、localStorage 與網址列 `?lang` 行為不變。
- 77 個靜態預渲染頁（`/event/…`、`/scores/<分類>/`、`/source/<facet>/<值>/`）本來就是單一語言（zh-Hant）、自我 canonical、無 hreflang，維持不變。
- 舊 slug：`serve.py` 只對 `data/sources/source-url-aliases-served.csv` 列出、且 registry 為 301、且目標仍是該 public ID 目前頁面的列回 301，保留 query。
- RSS GUID 加 `isPermaLink="false"`（sources 與 updates 類 feed），GUID 值不變。

- `/`、`/events/`、`/post/`、`/source/`、`/scores/`、`/feeds/`、`/submit/`、`/contribute/`、`/status/`、`/api/v1/health`、`/robots.txt`、`/sitemap.xml`、`/feeds/sources.xml` → `200`；`/directory/` → `308 /source/`。
- `/source/189-fcu-harmonica/`（帶 `Accept-Language: zh-TW`）：`<html lang="en">`、canonical 與 og:url `https://harmonica.observe.tw/source/189-fcu-harmonica/`；`?lang=en` canonical 同無參數；`?lang=zh-Hant|ja|ko` 自我 canonical；5 個 hreflang 一致。瀏覽器 JS 渲染後 canonical／hreflang 與伺服器一致，切換英文後網址列為 `?lang=en`、canonical 為無參數 URL。

- `/feeds/sources.xml` 三個 GUID 皆為 `<guid isPermaLink="false">`。
