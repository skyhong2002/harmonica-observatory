# 하모니카 관측소 · Harmonica Observatory

[English](README.md) · [繁體中文](README.zh-Hant.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**전 세계의 하모니카 행사, 연주자, 악보 정보를 한곳에서 찾아보세요.**

하모니카 정보는 여러 소셜 플랫폼과 웹사이트, 언어에 흩어져 있습니다. 하모니카 관측소는 공개 행사, 게시물, 연주자, 앙상블, 동아리, 교육 자료와 악보 출처를 모아 연주자, 강사, 학생, 애호가가 정보를 찾고 원본 출처에서 자세히 확인할 수 있도록 돕습니다.

**[하모니카 관측소 방문하기](https://harmonica.observe.tw/)** · [GitHub](https://github.com/skyhong2002/harmonica-observatory) · [행사 찾기](https://harmonica.observe.tw/events/) · [출처 둘러보기](https://harmonica.observe.tw/source/) · [악보 찾기](https://harmonica.observe.tw/scores/)

인터페이스는 **English, 繁體中文, 日本語, 한국어**를 지원합니다. 익숙한 언어로 여러 국가와 지역의 콘텐츠를 탐색할 수 있으며, 인터페이스 언어와 국가 필터는 서로 독립적입니다.

## 데이터 안내

- **원본 출처를 보존합니다.** 게시물은 원문과 원본 링크를 유지합니다. 출처 이름과 소개에는 참고용 번역을 제공하며, 등록된 원래 이름과 원문도 확인할 수 있습니다.
- **확인 가능한 데이터에 따라 표시합니다.** 행사는 원래 시간대를 유지합니다. [상태 페이지](https://harmonica.observe.tw/status/)에서 데이터 갱신 시각과 플랫폼 상태를 확인할 수 있습니다. 수록 범위와 갱신 빈도는 출처의 이용 가능 여부에 따라 달라집니다.
- **악보는 색인 중심입니다.** 지정곡 정보, 공식 근거 자료, 출판 정보를 수록합니다. 모든 항목에서 전체 악보를 내려받을 수 있는 것은 아니며, 허가받지 않은 파일은 제공하지 않습니다.
- **스토리에는 표시 기한이 있습니다.** 캐시된 스토리는 원래 게시 시각부터 48시간 동안 표시되며 카드에 만료 시각이 안내됩니다. Instagram 원본은 더 일찍 만료될 수 있습니다. 페이지는 매분, 그리고 탭으로 돌아올 때 갱신됩니다.

## 하모니카 정보를 함께 모아 주세요

아직 등록되지 않은 연주자, 단체, 행사, 악보 출처를 알고 계시거나 수정할 정보를 발견하셨나요? [정보 제보 및 수정 요청](https://harmonica.observe.tw/submit/)으로 공개 URL과 설명을 보내 주세요. 각 콘텐츠에도 관련 정보를 미리 채워 주는 제보 링크가 있습니다. 제보는 검토 후 공개 데이터에 반영됩니다.

소셜 소식의 지속적인 수집을 지원하려면 [Apify 이용 한도 기여](https://harmonica.observe.tw/contribute/)를 이용할 수 있습니다. 누적 지출 상한을 설정하고 언제든 권한을 철회할 수 있습니다. 페이지에는 수집 용량과 갱신 빈도의 예상치가 표시되며, 실제 갱신은 출처와 수집 결과에 따라 달라집니다.

기여 내역과 제보를 Google 계정에 연결하면 여러 기기에서 관리할 수 있습니다. 로그인하면 현재 브라우저의 미연결 기록이 계정으로 이전됩니다. 로그인하지 않아도 원래 브라우저의 보안 쿠키로 관리할 수 있습니다. 계정에 연결하기 전에 쿠키를 삭제했다면 Apify에서 원래 토큰을 폐기해 주세요. Google 로그인은 Google Calendar 권한을 요청하지 않습니다.

개발자는 코드, 인터페이스 번역, 공개 출처 데이터 개선에도 참여할 수 있습니다. 아래에 로컬 실행 방법, 데이터 구조, 검증 명령을 안내합니다. 출처를 추가하기 전에 [출처 수록 규칙](.agents/AGENTS.md)을 읽고, 배포에는 [로컬 호스팅 안내](deploy/local-hosting.md)를 따라 주세요.

## 로컬 실행

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build_local.py
.venv/bin/python scripts/serve.py --host 127.0.0.1 --port 8330
```

**http://localhost:8330/** 을 여세요. 빌드된 데이터가 이미 있다면 `serve.py`를 바로 실행할 수 있습니다.

`build_local.py`는 로컬 CSV와 기존 수집 스냅샷으로 사이트 데이터를 생성합니다. 새 데이터를 가져오거나 유료 actor를 실행하거나 AI를 호출하거나 Git에 push하지 않습니다. 비공개 런타임 스냅샷이 없는 새 clone에서는 먼저 CSV 출처 목록과 악보 색인을 제공하며, 이후 파이프라인에서 게시물을 수집합니다.

macOS 백그라운드 서비스 설치:

```bash
.venv/bin/python scripts/install_local_service.py --install \
  --public-origin https://harmonica.observe.tw
```

Caddy, DNS, HTTPS, 백업, 예약 실행, 복구에 관한 자세한 내용은 [로컬 호스팅](deploy/local-hosting.md)을 참고하세요. DNS는 관리자가 변경하며 애플리케이션에서 변경하지 않습니다.

## 구조

```text
web/                       4개 언어 UI, 공통 구성 요소, 화면, 로케일
scripts/global_catalog.py  기존 데이터를 일관된 글로벌 공개 모델로 정규화
scripts/serve.py           로컬 HTTP 라우트, 공개 API, 동일 출처 및 CSRF 검사
scripts/community.py       Apify 토큰 암호화, 예산, 브라우저 식별, 제보
scripts/apify_pool.py      수집 프로세스 간 예산 공유, 원자적 예약, 계정 순환
scripts/llm_backend.py     AI 게이트웨이 구조화 추론 및 호출 제한
data/sources/              안정적인 public_id를 사용하는 Git 관리 대상 공개 CSV
site/                      생성된 JSON, RSS, ICS, 이전 URL 페이지, 이미지 캐시
state/                     비공개 SQLite, 키, 분류 캐시(Git 제외)
data/feeds/                로컬 수집 수신함 및 게시물 후보(Git 제외)
```

HTTP 요청은 스냅샷만 읽습니다. 인터페이스 언어를 바꿔도 AI 게이트웨이나 Apify를 호출하지 않습니다. 수집 프로세스와 웹 서비스가 분리되어 있어 외부 서비스에 일시적인 장애가 발생해도 기존 데이터를 볼 수 있습니다.

스토리 수집은 Chumei의 방식을 참고하여 활동 중인 출처를 우선하고, 간격을 조절한 배치로 진행합니다. 각 배치는 하나의 Apify 계정의 지출 및 결과 용량을 기준으로 계획하며, 기존 예산 제한과 원자적 예약을 유지합니다. 수집 후 `scripts/publish_story_cache.py`가 필요한 데이터만 처리하고 오프라인 RSS/JSON을 즉시 발행합니다. 프로필, YouTube, Facebook 또는 전체 게시물 처리 주기의 완료를 기다리지 않습니다. [Apify 수집 및 예산 규약](deploy/apify-pool.md)을 참고하세요.

### 데이터와 URL

- `data/sources/harmonica-source-watchlist-public.csv`: 주요 공개 출처 목록.
- `data/sources/harmonica-clubs-public.csv`: 학생 동아리.
- `data/sources/harmonica-score-publications.csv`: 대회 지정곡과 공식 근거 자료.
- `data/sources/harmonica-score-sources.csv`: 출판 및 악보 구매 정보.
- `data/sources/harmonica-public-calendar-overrides.csv`: 공개 근거가 있는 행사 수정 사항.
- `data/sources/source-url-aliases.csv`: 기존 출처 URL의 별칭.
- `data/sources/source-name-translations.json`: 검토된 4개 언어 참고 이름. 등록된 원래 이름과 출처를 유지하며 공식 명칭이라고 주장하지 않습니다.
- `data/sources/source-description-translations.json`: 출처 소개와 태그의 4개 언어 번역. `event-description-translations.json`에는 행사 요약의 번역을 저장합니다. 원본 기록과 정확히 일치할 때만 번역을 사용합니다. 상세 페이지, SSR, SEO는 인터페이스 언어를 따르며 원문을 펼쳐 볼 수 있습니다. `scripts/validate_description_translations.py`로 새 데이터의 번역 누락을 검사할 수 있습니다. 방문자의 탐색으로 번역 서비스를 호출하지 않습니다.
- `data/sources/score-source-media.json`: 개별 확인한 책 표지, 공지 이미지, 원본 페이지. 로컬 미리보기를 다시 생성하려면 `.venv/bin/python scripts/cache_score_source_images.py`를 명시적으로 실행하세요. 방문자 요청이나 오프라인 빌드 과정에서 이미지를 가져오지 않습니다.

`public_id`는 정렬하거나 새 기록을 추가해도 바뀌지 않습니다. `country`는 주 소속 국가·지역이며, `region`은 더 세부적인 지리 정보입니다. 위치를 알 수 없으면 국가를 기본값으로 지정하지 않습니다. 출처를 추가할 때는 `.agents/AGENTS.md`에 따라 공식 프로필 이미지와 공개 소개를 확보하고 출력을 검증하세요.

### 수집과 Apify

Facebook 게시물, Instagram 게시물과 스토리는 하모니카 관측소 전용 Apify 풀을 공유합니다. YouTube, 웹사이트, RSS/RSSHub는 기존 공개 경로를 계속 사용하며 인터페이스 변경으로 중단되지 않습니다. 가용 예산, actor별 한도, 프로세스 간 예약을 함께 적용해 지출을 제한합니다. 결과가 확인되지 않은 작업은 예약을 유지하며, 재시도로 예산 한도를 우회하지 않습니다.

```bash
# actor를 실행하지 않고 이용 한도 정보 갱신
.venv/bin/python scripts/apify_pool.py --refresh

# 수집 및 빌드 실행(설정된 Apify/AI 게이트웨이 이용 한도를 사용할 수 있음)
.venv/bin/python scripts/run_pipeline.py
```

[Apify 풀](deploy/apify-pool.md)과 [Instagram 수집 세부 사항](deploy/instagram-public-ingestion.md)을 참고하세요. 로컬 배포에는 `--publish-pages`가 필요하지 않습니다. [이전 Pages 절차](deploy/github-pages.md)는 대체 배포를 위한 참고 자료로 유지합니다.

### AI 게이트웨이 추론

기본값은 `HARMONICA_LLM_PROVIDER=gateway`입니다. 관리자 작업(분류, 캘린더 검토, 디렉터리 태그, 양식 제출 검토)은 로컬 AI 게이트웨이(`http://127.0.0.1:8317/v1`)에 OpenAI 호환 형식으로 의미 기반 별칭만 지정해 요청합니다. 분류는 `sky-fast`, 제출 검토는 `sky-quality`입니다. 실제 모델은 게이트웨이가 정하며, 응답에 표시된 실제 모델을 요청한 별칭과 함께 기록합니다. 키는 `HARMONICA_LLM_API_KEY` 또는 Keychain 항목 `harmonica-ai-gateway` / `harmonica`에서 읽습니다.

- 4개 언어 UI는 정적 로케일 파일을 사용하므로 방문자 동작에 따른 AI 번역 비용이 없습니다.
- 모든 작업이 동시 요청 1건과 시간당 한도(`HARMONICA_LLM_MAX_CALLS_PER_HOUR`, 기본 120)를 공유하며, 한도에 도달하면 캐시를 유지합니다.
- `HARMONICA_LLM_PROVIDER=disabled`로 새 추론을 완전히 비활성화할 수 있습니다.

방문자에게 게이트웨이 키나 임의 추론 엔드포인트를 제공하지 않습니다.

## 공개 API

| 경로 | 용도 |
| --- | --- |
| `/api/v1/health` | 로컬 서비스 상태 확인 |
| `/api/v1/catalog` | 전체 글로벌 데이터 스냅샷 |
| `/api/v1/sources` | 출처 목록 |
| `/api/v1/posts` | 원문 게시물 |
| `/api/v1/events` | 날짜와 시간대가 명확한 행사 |
| `/api/v1/scores` | 대회 지정곡 |
| `/api/v1/community` | 커뮤니티가 허용한 이용 한도와 수집 빈도 예상치 |

목록 API는 `q`, `country`(예: `JP`, `KR`), `limit`(1–200), `offset`을 지원합니다. 기존 `/api/sources.json`, `latest.json`, `scores.json` 등도 계속 읽을 수 있습니다. 공개 데이터에는 공개 정보와 허용된 집계 상태만 포함하며 토큰은 반환하지 않습니다.

RSS/ICS는 `/feeds/` 아래에서 계속 제공됩니다: `updates.xml`, `events.xml`, `posts-videos.xml`, `sources.xml`, `student-clubs.xml`, `opportunities.xml`, `public-calendar.ics`, `overseas-calendar.ics`, `online-calendar.ics`.
